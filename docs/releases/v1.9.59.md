Status: published under the maintainer's standing authorization for fixes, typed on 2026-10-15: "Fix things when
they're broken. Don't ask me permission." Cut from `main` at `81c07e43`, after #1493 landed and before the #1510 write

## Before you upgrade

No public API change, no conversion and no storage change. 1.9.58 opens a store this version has opened.

## Release focus

**A query observation is one stream** (#1493; red `02ef83f5`, green `6256949a`, exercise `c5f7c882`, doc `b00e2d04`,
merge `dffd9a06`). The store yields an observer's results straight into the observation's output, and a live query's
server error writes into the same output under the same lock. Deferred values, the typed decode and a `map` run in the
consumer's pull. The forwarding tasks between the store and the view are gone. A fetch wrapper tells Observation only
about the members an emission changed.

Measured on a Mac mini (M4, release), `InstantObservationExercise` (48 live `@FetchAll` observers):

| Measure | Before | After |
| --- | --- | --- |
| library tasks kept per open live `@FetchAll` | 7 | 1 |
| tasks alive in the process with 48 live observers (xctrace) | 290 | 50 |
| store publication to the wrapper's value, p50 | 2,631 us | 681 us |
| store publication to the wrapper's value, p99 | 6,202 us | 3,754 us |

Tasks per open observation, by kind: raw live 5 to 0, local 2 to 0, deferred 6 to 0, typed 6 to 0, mapped 7 to 0,
`@FetchAll` 7 to 1 (its own consumer).

Also on `main` since 1.9.58 and outside the library's products: `InstantObservationExercise`, the exercise above, and
`scripts/contention-exercises/run-observation-exercise.sh`.
