Status: published under the maintainer's standing authorization for fixes, typed on 2026-10-15: "Fix things when
they're broken. Don't ask me permission." A release branch off `v1.9.59` (`1d9ba2ba`) with #1491's four source and

## Before you upgrade

No public API change, no conversion and no storage change. 1.9.59 opens a store this version has opened.

## Release focus

**A local write does less hashing** (#1491; red `cd3faf28`, green `d564a099`, red `aa18c4af`, green `4ff5e5c4`, merge
`99a46951`).

- A SHA-256 digest's lowercase hex is written into one string's storage, not formatted as 32 strings and joined. The
  save computes two digests a write.
- A row write fingerprints the forward wire intent only for a row that holds an acceptance or was offered. A new
  local write computed that fingerprint once a write and never read it.

Measured on a Mac mini (M4, release), the cross-SDK runtime benchmark, 300 transacts, three runs each, one job
(`13cdf499` before, `4ff5e5c4` after):

| Measure | Before | After |
| --- | --- | --- |
| tight-loop `transact`, p50 | 0.476 ms | 0.389 ms |
