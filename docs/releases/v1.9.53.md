# Instant Swift Data 1.9.53

Status: published under the maintainer's standing authorization for fixes, typed on 2026-10-15: "Fix things when
they're broken. Don't ask me permission." Cut at `1c5fc76d` (#396). It carries 1.9.52.

## Before you upgrade

No migration, no stored format change, no public API change. The package's minimum visionOS is now 2. An app that
deploys to visionOS 1 cannot use this version.

## Release focus

**The package declares visionOS 2** (#396). With no visionOS line in `platforms`, SwiftPM built the package for
visionOS 1. A `*` in an availability list covers any platform it does not name, at the package's minimum, so the
stored-value reader's check let through code that needs visionOS 2, and the build stopped. One line fixes the whole
class: the minimum now reaches what that code needs.

## Checks

On a Mac mini (2026-10-30 11:06-11:07): `InstantSwiftDataCore`, `InstantSwiftData`, `InstantSwiftDataMedia` and
`AuthV3App` each cross-compile for the visionOS simulator with `swift build --triple arm64-apple-xros-simulator`.
Before the change the first target failed on this Mac with "'StoredValueReader' is only available in visionOS 2.0 or
newer". No other platform's build settings change, and no test bundle was run for this release: no source file changed.
