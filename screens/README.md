# VoiceTrail Screen Sketches

The screen sketches are versioned because they are syntax probes, not
shipping UI.

- `screens/v2/` contains the original V2 sketches.
- `screens/v3/` contains the V3 sketches for call-site callbacks,
  message-based actions, rooms, presence, topics, local IDs, sync
  status, queryable files, request objects, projection builders, and
  generated change envelopes.

Use these files to judge how the public API feels in realistic SwiftUI
files before implementation hardens around a particular shape.
